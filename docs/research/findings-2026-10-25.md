# Research findings, October 25, 2026

All notes from the evaluation of The Agora LA: what the code does, what was observed, and what the research found. Estimates are labeled. Items not confirmed against a primary source are marked **unverified**.

---

## 1. What the app is

A free, nonprofit iOS app for active listening. A listener pastes an Apple Podcasts, RSS, or audio link; the app builds a timed transcript, writes questions grounded in the episode, and asks each one right after the passage that answers it. Hands-free mode (on by default) pauses playback, reads the question aloud, takes a spoken answer, grades it generously, reads feedback, and resumes. No accounts, no in-app purchases; listeners connect their own OpenRouter account through OAuth PKCE.

| Part | Stack | Size |
|---|---|---|
| iOS app (`Sources/`) | SwiftUI, iOS 16+, no third-party packages, AVFoundation, Apple Speech, local JSON library | ~12,500 lines |
| Backend (`Backend/`) | Node 24, Fastify 5, Postgres (queue and results), FFmpeg, OpenAI SDK pointed at OpenRouter | ~2,100 lines, 44 tests |
| Website (`Website/`) | Next.js 16 on Cloudflare Workers | small |

## 2. Code review findings

### Pipeline (cloud path)

1. **Resolve** on the phone: Apple Podcasts link → iTunes Lookup → RSS → MP3 (`Sources/PodcastImportService.swift`).
2. **Transcript**: publisher `<podcast:transcript>` when it covers ≥90% of the episode; otherwise download (≤250 MB), split into 8-minute AAC parts with FFmpeg, transcribe 3 at a time with Whisper large-v3, re-offset timestamps (`Backend/src/transcription.ts`).
3. **Extract**: 3–12 sections by duration, ≤2,800 words each, 4 in parallel, "low" reasoning (`Backend/src/promptPipeline.ts`).
4. **Verify**: drop ideas whose quote isn't verbatim in the transcript, importance < 0.55, or duplicates.
5. **Curate**: one "high" reasoning call, up to 18 candidates plus a 100–170-word summary; deterministic gates (score ≥ 0.72, word counts, stock-question list, token-overlap alignment, timeline spread).
6. **Schedule**: prompt time = end of the segment holding the last supporting quote + 3 s; model-supplied times are ignored (`Backend/src/transcriptTiming.ts`).

### What already scales

- Postgres queue with `FOR UPDATE SKIP LOCKED`, claim tokens, 2-second heartbeats, requeue after 3 minutes (`Backend/src/worker.ts`).
- Per-listener keys: no central AI bill or shared rate limit.
- SSRF-safe fetching with DNS pinning (`publicFetch` in `transcription.ts`).
- AES-256-GCM key encryption at rest, erased when jobs end.

### Defects and risks found

| # | Finding | Where | Impact |
|---|---|---|---|
| a | Phone curation caps output at `min(16000, 2500 + candidates × 750)` tokens with "high" reasoning; extraction caps at 3,500 | `Sources/OpenRouterClient.swift:222`, `:316–317` | Empty or truncated JSON → "The AI returned an unreadable response" (matches the simulator test) |
| b | Phone transcription rejects a whole 8-minute part if any segment is empty or zero-length | `Sources/OpenRouterClient.swift:978–984` | Music or silence segments can fail transcription |
| c | Any transcription model without "whisper" in its name is replaced by Whisper large-v3 | `Backend/src/openAIClient.ts:16` | Blocks Qwen3-ASR and other models |
| d | Only the curation model follows the listener's tier; extraction always uses gpt-5.6-terra | `Backend/src/analysisService.ts:74–76`, `config.ts` | "Economical" and "Free" tiers still pay ~$0.25–0.45 per hour of audio |
| e | Job dedupe key includes title, model, and prompt count, per user only | `Backend/src/app.ts:277–287` | No sharing across listeners; repeated work and cost |
| f | All-or-nothing jobs, no stage checkpoints | `processEpisodeAnalysis` | A failed quality gate discards paid transcription and extraction |
| g | Two different pipelines: TypeScript server and Swift phone fallback | `Backend/src`, `Sources/AIService.swift`, `OpenRouterClient.swift` | Logic drift; the Swift path is live whenever the cloud is down |
| h | API and worker share one process; no metrics; app polls, no push | `Backend/src/server.ts` | Operations visibility |
| i | Apple IAP and credit-ledger code remains though v1.0 is free | `Backend/src/app.ts`, `appleBilling.ts`, migrations | Dead weight |
| j | Retention purge filters on `created_at` without a matching index | `Backend/src/worker.ts`, migrations | Minor at scale |

Throughput estimate: ~4–8 minutes per hour-long episode; 2 jobs per instance by default (max 4), so ~15–60 episodes per hour per instance.

## 3. Simulator test (iPhone Duo, iOS 27.1)

- Episode: "Ep. 40 – Nature of Consciousness", feed `https://rss.art19.com/being-in-the-way`, 1,719 s.
- The feed has 42 items and no `<podcast:transcript>` tags, so the phone transcribed the audio with Whisper large-v3 through OpenRouter.
- Saved state: 4,634-word transcript with timing markers (~161 words/minute, complete), 0 prompts.
- Error: "The AI returned an unreadable response. Please try again." (`OpenRouterClientError.invalidResponse`). The fast path's invalid response falls back to the legacy path, which failed the same way.
- Likely cause: finding (a). Confirm with the request's finish reason at openrouter.ai/activity.
- Separately, the app icon looked gray on the simulator home screen. The simulator was in light mode; the asset catalog holds only legacy PNG icons (no Icon Composer file, no dark or tinted variants). Cause not confirmed.

## 4. Cost model

Estimates for a 60-minute episode: ~9,000 words, ~20,000 tokens with timestamp markers, 8 extraction calls, 1 curation call. Reasoning tokens are not logged, so ranges are wide.

| Tier (cloud path) | Models | Est. per episode |
|---|---|---|
| Balanced (default) | gpt-5.6-terra extraction + curation | ~$0.40–0.80 |
| Maximum | terra + gpt-6-astra curation | ~$0.80–1.90 |
| Economical | terra + gpt-5.6-luna | ~$0.25–0.45 |
| Small current models | Claude Haiku 5.5 or gpt-6-luna for both | ~$0.02–0.03 |

Plus transcription (~$0.03/hour, or $0 with a publisher transcript) and grading (~1¢ per answer on terra, <0.1¢ on Haiku 5.5).

OpenRouter prices on October 25 (input / output per 1M tokens): gpt-6-astra $10 / $50; gpt-5.6-terra $2 / $12; claude-sonnet-5.5 $2 / $10; claude-opus-5.5 $4 / $20; gpt-5.6-luna $0.20 / $1.20; claude-haiku-5.5 $0.10 / $0.50; gpt-6-luna $0.10 / $0.50; deepseek-v4-flash $0.09 / $0.18; gemini-3.5-flash-lite $0.30 / $2.50.

### Recommended open-source stacks

- **Server (Python):** `qwen-asr` with the vLLM backend running Qwen3-ASR-1.7B; ForcedAligner-0.6B on ≤5-minute silence-cut windows offset onto the full timeline; pyannote community-1 for speaker labels mapped onto word times. One L4 GPU (Modal ~$0.80/hour; Cloud Run ~$1.05/hour for the minimum shape). Fallbacks: MOSS-Transcribe-Diarize (one pass up to 90 minutes, speakers, segment timestamps) or Parakeet v3 in NeMo.
- **iPhone:** FluidAudio (Apache-2.0, iOS 17+) running Parakeet TDT v3 with an fp16 encoder, plus pyannote or Sortformer v2. ~480 MB model; FluidAudio measured 16.5% WER on a 60-minute Earnings-22 test on a Mac (word drops at chunk seams); end-to-end iPhone speed unpublished. iOS 16 fallback: WhisperKit (less accurate).
- **Avoid:** Canary-1B and Sortformer v1 (CC-BY-NC); Cohere Transcribe and Granite Speech 5.0 (no timestamps); gpt-transcribe (no documented timestamps); streaming-first models.

Self-hosting saves little at small scale: ~1–2¢ per audio hour versus 2.9¢ on OpenRouter, and cold starts erase the difference for one-off episodes. It pays off with steady volume, speaker labels, or privacy needs.

| Source | Status | Notes |

| Uploaded files | Allowed | Needs upload flow and storage |

## 7. Bring-your-own-AI over MCP (explored, then dropped)

Kept for reference; the strategy was dropped on October 25, 2026.

- A remote MCP server can be added by users as a Claude connector (Free plan: one custom connector; works on mobile once added). Install link format: `https://claude.ai/customize/connectors?modal=add-custom-connector&connectorName=NAME&connectorUrl=ENCODED_URL`.
- Claude's connector limits: tool results ~150,000 characters, 240 seconds per call; sampling not supported.
- Policy: third-party apps may not use a listener's Claude.ai or ChatGPT subscription programmatically; OpenAI's "Sign in with ChatGPT" plan usage is a limited preview for open-source and locally run apps.
- MCP sampling was deprecated in the 2026-07-28 specification.
- Claude Code scheduled tasks can run connectors unattended (research preview, Pro and up); an app firing them with a stored trigger token is likely barred (unverified with Anthropic).
- OpenRouter's own MCP server (`mcp.openrouter.ai`) is a developer tool (7-day keys, $10 cap); its Agent SDK runs MCP tool calls in the developer's process.
- Why dropped: every quiz must start in a chat, real-time grading is impossible, and vendor policies block server-driven use.

## 8. On-device AI (Apple)

- **SpeechAnalyzer** (iOS 26+): free, no model download; ~14% WER on a vendor earnings-call test (Parakeet v2: 11.7%).
- **Foundation Models** (iOS 26+, Apple Intelligence devices, iPhone 15 Pro and later): ~3B parameters, 4,096-token context per session, structured output with `@Generable`, free. Suitable for grading short answers against an expected answer; not for full-transcript question writing without heavy chunking. Latency unpublished.

---

## 9. Platform and longevity advice

1. Keep SwiftUI for the iPhone app (first-party framework, zero packages, direct access to Apple-only features).
2. Keep one pipeline, on the server; make the phone a thin client.
3. Use open formats at the edges: RSS, timestamped transcripts (`[[AUDIO_SECONDS]]` or WebVTT), OpenAI-style APIs.
4. Put transcription, question writing, and grading behind small adapters so models can be swapped.
5. Add accounts, sync, and export so listener history survives device changes.
6. Avoid a React Native rewrite; add a web client or thin Android client against the same server if reach is needed.
